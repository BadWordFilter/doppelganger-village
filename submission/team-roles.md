# 팀원 롤 기술서 — 도플갱어 마을 탈출

## 팀원별 역할

| 이름 | 담당 역할 | 실제로 맡아 구현·수행한 영역 |
|---|---|---|
| **김보민** | 기획 | 게임 기획서 작성 — 세계관·코어 루프(대화 추리·거울 판정)·식별 기믹 5종 설계, 게임의 최대 자산인 **동물 9종 대화 테이블 200개 원작 집필**. 낮/밤 사이클·구역 확장·개인 과제 등 시스템 기획과 밸런스 수치 결정, 반복 플레이테스트로 재미 기준 검증 |
| **김수연** | 모델링·아트 | 아트 디렉션 — 캐릭터 조형 문법(2등신 치비·큰 눈·ㅅ자 입) 결정과 레퍼런스 큐레이션, Blender 절차 모델링 파이프라인의 결과물 감수·리테이크 지시(종별 실루엣 차별화·라운드 정도·얼굴 비례), 마을·집 내부·UI 룩앤필 품질 검수 |
| **이학주** | 코딩·개발 | Unity 6·Photon PUN 2 멀티플레이 아키텍처(마스터 권한 판정·버퍼 RPC) 구현 감수, AI(Claude Code) 개발 디렉팅과 코드 리뷰, WebGL 빌드·GitHub Pages 배포·Photon 계정 관리, 통합 QA와 버그 리포트 |

## 협업·분업 방식

- **기획(김보민) → 구현(이학주) → 아트 검수(김수연)**의 파이프라인으로 진행하되, 매 빌드를 전원이 함께 플레이하며 카카오톡·스크린샷으로 피드백을 모았습니다.
- 구현 실무는 AI(Claude Code)가 Unity 에디터를 MCP로 직접 조작하는 방식으로 수행했고, 팀은 **결정·감수·검증**을 담당했습니다 — 기획 의도 판정(김보민), 아트 품질 판정(김수연), 기술 방향·코드 품질 판정(이학주). 세부 내역은 「AI 활용 기술 문서」와 리포지토리 `submission/ai-log.md` 참조.
- 피드백 루프: 플레이 → 피드백 전달 → AI 구현·자율 검증 → 웹 자동 배포 → 재플레이. 이 사이클을 개발 기간 내 20회 이상 반복하며 게임을 다듬었습니다.
