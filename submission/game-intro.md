# 도플갱어 마을 탈출 (Escape from Doppelganger Village)

> **한 줄 소개**: 주민의 탈을 쓴 도플갱어에게 점령당한 마을 — 대화 속 미묘한 위화감으로 진짜 주민을 가려내 구출하고, 트레일러를 수리해 탈출하는 1~4인 협동 추리 호러.

## 1. 게임 개요

트레일러를 타고 이동하던 플레이어들은 사고로 낯선 마을에 고립됩니다. 마을은 이미 주민(동물)으로 위장한 도플갱어에게 점령당했습니다. 유일한 단서는 바닥에 떨어진 쪽지 한 장:

*"만약 도플갱어라는 확신이 들었다면, 눈을 감고 거울을 비추십시오."*

집집마다 들어가 동물 주민과 대화하고, 답변 속 모순 — 생태적 오류, 기억의 균열, 기괴한 반응 — 을 근거로 **진짜 주민인지 도플갱어인지 판정**하세요. 진짜를 구출하고 수리 부품을 모으면 트레일러를 고쳐 탈출할 수 있습니다.

- 장르: 협동 추리 / 소셜 디덕션 호러 (귀여운 로우폴리 → 기괴한 반전)
- 인원: 1~4인 (혼자서도 전체 플레이 가능, 4자리 룸 코드로 친구 합류)
- 플랫폼: 웹 브라우저 (PC Chrome 권장)
- 볼륨: 낮/밤 사이클 · 동물 9종(주간 6종 + 야행성 3종) · 기획서 대화 테이블 200개 전량 탑재 · 단계식 구역 확장

## 2. 플레이 방법

### 게임 흐름
`방 만들기 → 대기실에서 캐릭터 색 커스터마이징·인원 확인 → 방장이 게임 시작`

### 목표 (단계식)
- **1단계**: 진짜 주민 **10마리** 구출 → 마을을 감싼 안개가 물러나며 **바깥 구역이 열리고 새 주민들이 나타납니다**
- **최종 승리**: 진짜 주민 **20마리** 구출 + 수리 부품 **10개** 수집 → 트레일러 수리, 탈출
- **패배**: 생존 플레이어 전원 감염(HP 0) / 구조할 주민 소진
- **감염되어도 끝이 아닙니다** — 느려진 몸으로 생존자를 습격하는 감염자가 되어 게임에 남습니다

### 핵심 규칙
1. 게임 시작 시 **떨어진 쪽지**가 생존 요령을 알려줍니다. 마을의 **집 문 앞에서 E로 문을 두드리면** 문이 열리며 들어갈 수 있고, 그 집에 사는 동물을 만납니다 (집은 12채 — 대부분 1마리, 가끔 2마리가 삽니다).
2. 질문 선택지 3개 중 골라 묻습니다. **동물 1마리당 질문은 최대 3회** (모든 플레이어가 공유).
3. 도플갱어는 거의 완벽하게 연기하지만, **핵심을 찌르는 질문이 반복될수록 본색을 드러낼 확률이 올라갑니다** (1번째 10% → 2번째 30% → 3번째 60%). 대사 속 울음소리와 행동은 실제 사운드·모션으로 재생됩니다.
4. **4번째 질문은 도박입니다** — 상대가 도플갱어면 눈치채고 돌변해 괴물이 되어 **집 밖까지 당신을 추격**하고, 진짜 주민이면 겁먹고 도망쳐 **구출에 실패**합니다. 낮에 잡히면 HP가 깎이고 기절하지만, **밤에 잡히면 즉시 감염**됩니다. 가까워질수록 심장 소리가 빨라집니다.
5. **질문을 모두 쓰면 반드시 판정해야 합니다** (떠날 수 없음):
   - **트레일러로 보내기 (E)** — 진짜 주민이라 확신할 때. 정답이면 아이템(수리 부품·구급상자·붕대·식량)을 떨어뜨립니다 — **가까이 가서 E로 주워야 획득**
   - **눈을 감고 거울 비추기 (F 또는 우클릭)** — 도플갱어라 확신할 때. 정답이면 퇴치. **진짜 주민에게 거울을 비추면 겁먹고 도망치고, 비춘 사람도 HP를 잃습니다**
6. **도플갱어를 트레일러로 보내면 겉보기엔 아무 일도 일어나지 않습니다.** 정산에서 잠입이 공개되고, 잠입 1마리당 구출 주민 수가 1 차감됩니다.
7. **트레일러 내부**: 트레일러 문 앞에서 E로 들어가면 구조된 주민들이 모여 있습니다. **E로 말을 걸면** 고마움과 힌트를 건넵니다 — 단, 잠입한 도플갱어는 침묵하거나… 웃습니다.
8. **낮/밤 사이클**: 낮(2분 30초)이 끝나면 해질녘 정산 후 밤(1분 30초)이 옵니다. 밤에는 시야가 좁아지고 랜턴에 의지해야 하며, 야행성 주민(올빼미·박쥐·늑대)이 깨어나고 돌변한 도플갱어들이 배회합니다. **야행성 주민 구출 = 수리 부품 확정.** 트레일러 안은 안전하며 HP가 회복됩니다.
9. **개인 과제** (좌상단 표시): 플레이어마다 매일 전담 구출 대상과 전담 부품이 배정됩니다. **전담 시민을 구출하면 전담 부품 확정 드랍** — 협동 분업의 핵심입니다.
10. **게임 종료 후**: [같은 팀과 다시 하기]로 새로고침 없이 같은 팀원과 즉시 리매치, [로비로 나가기]로 처음 화면 복귀.

### 조작
| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Space | 점프 |
| 마우스 | 시야 전환 (좌클릭으로 화면 잠금, ESC 해제) |
| Shift (유지) | 달리기 (스태미나 소모, 고갈 시 감속) |
| E 또는 좌클릭 | 대화 / 문 두드리기·출입 / 줍기 / 트레일러로 보내기 |
| F 또는 우클릭 | 눈을 감고 거울 비추기 |
| Tab | 조작키 확인 |
| ESC | 메뉴·설정 (음량·마우스 감도) |

## 3. 실행 방법

**설치 불필요 — 링크 접속만으로 실행됩니다.**

1. PC Chrome에서 접속: **https://badwordfilter.github.io/doppelganger-village/**
2. 로딩 후 `방 만들기` 클릭 → 대기실에서 `게임 시작` (1인도 가능)
3. 멀티플레이: 대기실의 **4자리 룸 코드**를 친구에게 공유 → 친구는 같은 주소에서 코드 입력 후 `입장` (최대 4인)
- 소스 코드: **https://github.com/BadWordFilter/doppelganger-village** (전체 소스·커밋 기록 공개)
